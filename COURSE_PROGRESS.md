## Правила ведения прогресса

- `[x]` — тема пройдена и закреплена.
- `[~]` — тема изучалась, но требует практики/закрепления.
- `[ ]` — тема ещё не изучалась.
- Не считать тему полностью пройденной только после теоретического объяснения:
  желательно иметь практическое задание.
- Если тема уже отмечена `[x]`, не проходить её заново без необходимости.
  При необходимости делать только краткое повторение.
- При переходе к новой теме сначала сверяться с этим файлом.
- После завершения существенной темы обновлять этот файл.

# Текущая точка

**Текущий практический проект:** калькулятор стоимости заказа с проверкой ввода и сохранением результата в файл.

**Что сделано на практике:**
- функции `get_num()`, `get_price()`, `save_order()`;
- повтор ввода при `ValueError`;
- проверка положительного количества и цены;
- подсчёт общей стоимости в цикле;
- создание папки `orders` через `Path.mkdir()`;
- запись результата в `order.txt`;
- обработка `OSError` при сохранении;
- проверка типа `total` через `isinstance()`, исключение `bool` из допустимых значений;
- исправление логического условия с `not` и `or`.

**Текущая тема:** обработка ошибок и проверка данных на примере калькулятора заказа. Базовые исключения уже применялись на практике; не начинать их объяснение с нуля.

**Следующий шаг:** продолжить улучшение текущего проекта: проверить конечность числовой суммы (`nan`/`inf` и `math.isfinite()`) и затем практично проверить сценарий ошибки сохранения. После закрепления перейти к следующей новой теме без повторения освоенной базы.
